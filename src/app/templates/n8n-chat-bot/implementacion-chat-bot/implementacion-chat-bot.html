📚 Guía de Uso con Tema Dinámico

🔧 Propiedades @Input

  • config - Configuración completa del chat
  • chatTitle - Título del chat
  • chatSubtitle - Subtítulo del chat
  • chatWidth - Ancho del contenedor
  • enableAutoTheme - Habilita tema automático
  • customColors - Colores personalizados
  • containerClass - Clases CSS adicionales

📡 Eventos @Output

  • onMessageSent - Cuando se envía un mensaje
  • onResponseReceived - Cuando se recibe respuesta
  • onError - Cuando ocurre un error
  • onChatCleared - Cuando se limpia el chat
